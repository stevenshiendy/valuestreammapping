# Flow Lab: Value Stream Mapping in Construction

Interactive explainer for the article *Value Stream Mapping for Material Flow Optimization in Construction Projects* by Steven Glenn Shiendy (MGMT6564032 Global Supply Chain Management, LA76, BINUS University Bandung).

## Publish on GitHub Pages
1. Create a new public repository and upload `index.html` (and this README).
2. Go to **Settings > Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

Case figures are simulated for teaching purposes and calibrated from the open-access studies listed on the page.
